# Biswajit Biswaranjan Sahoo — Portfolio

A modern responsive portfolio built with Next.js, React, TypeScript and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Personalize before deployment

Edit `app/page.tsx` near the top:

- `profile.email`
- `profile.github`
- `profile.linkedin`
- `profile.resume`

Put your real PDF resume at:

`public/Biswajit-Resume.pdf`

You can also edit the skills, projects and experience arrays in `app/page.tsx`.

## Deploy

Push the folder to GitHub and import the repository into Vercel. The default Next.js settings are enough.

## Contact form

The current form is a frontend demo: submission displays a confirmation message but does not send email. Connect it to your preferred backend/API provider when you are ready.
